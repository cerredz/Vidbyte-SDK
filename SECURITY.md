# Security Policy

## Supported Versions

Vidbyte SDK is currently alpha software. Security fixes are provided on a best-effort basis for the
latest published `0.1.x` release.

| Version | Supported |
|---------|-----------|
| 0.1.x | Yes |
| Earlier/unreleased versions | No |

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability.

Email [hello@vidbyte.ai](mailto:hello@vidbyte.ai) with the subject
`[Vidbyte SDK Security] <short summary>`. Include:

- The affected version, commit, and operating environment.
- A description of the impact and affected component.
- Reproduction steps or a proof of concept that does not expose third-party data.
- Any known mitigations or suggested remediation.
- A safe way to contact you for follow-up.

Do not include provider credentials, customer information, private prompts, or unrelated secrets.
Please allow maintainers time to reproduce and address the report before public disclosure.

Reports are reviewed and handled as maintainer capacity permits; this policy does not promise a
specific response or remediation deadline. Confirmed issues will be coordinated with the reporter,
fixed in a new release, and disclosed when a mitigation is available.

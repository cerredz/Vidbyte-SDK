# Adversarial review: A library of 250+ prebuilt agent tools in vidbyte-sdk

Diff reviewed: `origin/main..0fd73086` (worktree HEAD `8e283e51` adds only docs on top of it) · Lenses: conformance, conventions, engineering · Verifier: reports/S4-findings-verifier.md

## Verdict
MERGEABLE AFTER FIXES — The catalogue, schemas, and gates hold. The verifier confirmed 8 Blockers and 6 Majors, each with its own reproducer: two broken invariants, one broken model-facing contract, and five tools that take minutes, hours, or gigabytes on input their schemas accept. Every Blocker has a small, local fix. Three Majors (R-9, R-10, R-14) need a decision from the orchestrator or the test author before the repair.

**How every reproducer was run.** All commands run from the worktree on Python 3.11.0, the dev and CI interpreter:

```
PYTHONIOENCODING=utf-8 PYTHONPATH="$(pwd)" PYTHONDONTWRITEBYTECODE=1 timeout 120 python -u - <<'EOF'
import asyncio
from vidbyte.tools.toolsets import PrebuiltTools
from vidbyte.lib.enums import PrebuiltToolCategory
from vidbyte.tools.types import ToolCall
T = {t.name: t for t in PrebuiltTools(PrebuiltToolCategory)}
def call(n, a):
    r = asyncio.run(T[n].execute(ToolCall(n, a)))
    print(r.status.value, r.metadata.get("error_type"), r.output[:200])
call("<tool>", {...})
EOF
```

Each evidence cell gives the `call` arguments and the quoted result. Times are wall time through `FunctionTool.execute`. NFR-7's bar is 2 s per call at the largest input the schema allows. Its only exceptions are EC-10 (the regex tools) and EC-46 (`diff_words`, `closest_string_matches`, `unified_diff_text`), and none of the tools below is one of them. The phrase "the pack" means `python -m pytest -q -p no:cacheprovider tests/features/prebuilt_tools`. It gives `4310 passed in 21.11s` at HEAD with every finding present.

**How the fixes were prototyped.** Each "Prototype" in the fix column was applied in memory only, from a scratchpad module outside the worktree. With the R-1, R-2, and R-8 prototypes loaded together, the pack still gives `4310 passed in 20.41s`.

## What the implementation gets right (so nobody "fixes" it)
- **Schema fidelity.** The 265 tool schemas in 31 categories match the Appendix A rows: names, row order, parameter order, types, defaults, numeric bounds, lengths, and patterns. With `*_API_KEY` unset, the §4 snippet prints exactly the documented two lines (AC-1).
- **The error contract.** 234,900 schema-valid fuzz calls produced no `error_type` other than `validation` and `ToolExecutionError`, apart from R-3. 19,360 `ToolExecutionError` messages all match the INV-15 form, name a real parameter, and include no traceback.
- **Hardened JSON input.** `_support.parse_json_text` (`:79-120`) refuses NaN and Infinity, `1e400`, integers longer than 4,300 digits, and nesting deeper than 100 levels. It also turns `RecursionError` and `ValueError` into `ToolExecutionError`. These refusals keep INV-11 and INV-14 true, so keep them. `extract_json_from_text` already skips a literal `Infinity` correctly.
- **Exactness rules.** Compound growth gives 1647.01. The 200000 / 6% / 360-month loan gives 1199.10, a final payment of 1200.14, and 431677.04 in total. Rounding is half-even: 59.9996 s gives `1m`, 1500 ns and 2500 ns both give 2 µs, and 0.0005 gives `0s`.<br>Unit conversion is an exact `Fraction` with one `float()`, and every Float or NumberList parameter refuses `inf`.<br>`exact_arithmetic` and `number_formatting` already build an explicit `Context`, which is the model R-12 copies. Finance's money steps are exact in `Fraction`, with a single half-up rounding.
- **Boundaries and scope.** The PR adds 39 files and modifies 4, exactly as §12.3 plans, with no D-18 split. The largest module, `json_data.py`, has 582 lines. S3 changed no test. `lint/baseline.json` and the public API contract are unchanged. In `select_categories`, a `ToolRegistryError` names both the bad values and the valid values (INV-5).
- **Placement and layering.**
  - All 68 enums are `(str, Enum)`: 58 in `vidbyte/lib/enums/prebuilt_tools.py` and 10 in `units.py`. All are exported and in alphabetical order.
  - Caps and tables live in `vidbyte/lib/constants/`, and the lib modules import only `vidbyte.lib.enums`.
  - The PR adds no dataclass, `NamedTuple`, or `TypedDict`.
  - `PrebuiltTools(Tools)` copies the `CodingAgentTools` shape: its narrated `__init__` calls `select_categories` and then `get_tools` as sibling steps.
- **Call depth.** An AST scan of all 34 classes found one same-class two-hop chain, R-11. There are no nested defs. The nested classes (`_HtmlTextCollector`, `_TableParser`, `_LinkParser`, and `_CaseKeepingConfigParser`) each subclass a stdlib API to override a hook, and overriding `optionxform` at class level is the documented hook.

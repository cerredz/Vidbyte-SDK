## What the implementation gets right (so nobody "fixes" it)
- **The user's shape is exact.**
  - Six frozen, slotted entry subclasses each have a read-only `type` (`init=False`, so `type=` raises `TypeError`).
  - `GitHubSkill` and `SkillsShSkill` have no `text`, so `text=` raises `TypeError`.
  - Each source has one resolver module under `vidbyte/agents/skills/`, and `SkillLoader` stays under the hood.
  - The §4 snippet prints the five documented lines (AC-1), and the acceptance test copies §4 verbatim apart from one marked runner line.
- **The error and memory contract matches r4.**
  - `SkillLoader.load`, `JevSkillsPreload.run`, and `SkillFetch.get` have no broad `except`.
  - `SkillFetch.get` catches only `ProviderRequestError`, and a `TimeoutError` only when `deadline.expired()`. `SKILL_FETCH_DEADLINE_SECONDS` is read when the call runs.
  - Memory is written in one place with `setdefault`, after every group returns, so a crash or cancellation remembers nothing.
  - The transient set is exactly `{RATE_LIMITED, FETCH_FAILED}`.
  - The mutants `remember-transient`, `crash-remembers-siblings`, `loader-replaces-memory`, `loader-returns-fresh`, `deadline-at-import`, and `deadline-swallows-any-timeout` are killed.
- **The vendor fallback and archive reader are sound.**
  - The body may be a bare `SKILL.md` (optional BOM, capped) or a zip.
  - `latest` falls back to `latest_version`, then `latest_version_id`, only on 400, 404, or 422. An integer becomes text, and a bool is never a version.
  - A missing named version gets a distinct "content route was not found" detail.
  - The method, encrypted-flag, and declared-size checks run before the read. The engineering reviewer's fuzz of 40,000 mutated archives produced 0 escapes.
- **Every credentialed path is guarded against the Vidbyte key.**
  - The value is stripped, then prefix-checked, and the stripped value is the one sent.
  - Secrets are `field(default=None, repr=False)`, and details never echo a body.
  - Every request goes to a fixed host with `follow_redirects=False`, and `vb_live_` is spelled only through `VIDBYTE_API_KEY_PREFIX`.
- **Placement and layering follow AGENTS.md.**
  - Enums are in `lib/enums/skills.py`, and `SkillFetchStep` goes no further than `vidbyte.lib.enums`.
  - Records are in `lib/dataclasses/skills.py`, with `JevSkillResult` edited in place, and constants are in `lib/constants/skills.py`.
  - There is no `types.py` or `constants.py` in the package.
  - `agents/skills/*` imports only `vidbyte.lib` and its siblings, never `vidbyte.agents.jev` or the `vidbyte.agents` root.
- **Principle 1 holds.**
  - Every main (`load`, `parse`, `get`, and the six `resolve` methods) calls only leaf helpers or other classes. GitHub reaches `_GitHubAnswer`, per D-31.
  - There are no nested functions. The longest function is `run` at 47 lines, and the largest file is `vendor.py` at 213 lines.
- **Principle 5 holds for HTTP.**
  - One `SkillFetch.get` goes through `HttpTransport.request` with `timeout_seconds`, `retry_count`, `backoff_seconds`, `max_response_bytes`, and `follow_redirects=False`.
  - Status maps are dicts looked up by the integer status, never `HTTPStatus(status)`.
  - There is no retry loop.
- **The boundaries are clean.**
  - The budget matches §8.4: 14 new files, 12 package classes, 9 dataclass-module classes, 3 enums, 0 dependencies, and exactly 9 new root exports.
  - No file is touched outside §12.3, and `tests/` is unchanged since `d01e0afa`.
  - `lint/baseline.json` changes only A001 (643 → 642), and lint passes with no rule REGRESSED.
  - The contract is current at 615 exports, with 9 added and none removed.
  - Every pre-existing `@intent` is kept, and the internal names do not leak to the root.
- **Deviation 1 (`GITHUB_CREDENTIAL_ENV_VAR`) is necessary, not a dodge.** ruff S105 (inside S054) flags `GITHUB_TOKEN_ENV_VAR = "GITHUB_TOKEN"`, and renaming is the only fix that needs no suppression.

# Test plan: JevAgent skill sources — declarative skill entries resolved under the hood
Spec: `docs/spec/jev-skill-sources/spec.md` r3 · Framework: pytest 8.3.5 + pytest-asyncio 1.3.0 on Python 3.11.0 (PyYAML 6.0.2, httpx 0.28.1) · Prior art copied: `tests/test_jev_skill_preload.py` (Jev fakes through `DecisionModelHelper`), `tests/features/coding_agent/conftest.py` (fake `HttpTransport._send_once`), `tests/test_web_operation_client_retry.py` (patched transport backoff sleep), `tests/features/coding_agent/test_coding_agent_web_fetch.py` (sockets and subprocesses refused)

All new files live in `tests/features/jev_skills_preload/`; "`x.py`" below means `test_skill_sources_x.py` there. 90 test functions, 354 collected cases, plus the shared `conftest.py`. Levels: **acceptance** = `JevAgent.arun` with the transport and Jev faked at the spec's seams; **integration** = `SkillLoader` or `JevSkillsPreload` with real resolvers, parser, records, `zipfile`, `yaml`, and `tmp_path`; **component** = `SkillFetch` or `SkillMarkdown` called directly; **unit** = records and settings.

## Notes for the implementer
- **Names the tests bind to:**
  - From `vidbyte`: the nine public names.
  - `vidbyte.lib.enums.SkillFetchStep`.
  - `vidbyte.lib.dataclasses.skills.SkillResolution`.
  - `vidbyte.lib.constants.skills`: the constants in §9.3 and `SKILL_TRANSIENT_REASONS`.
  - `vidbyte.agents.skills`: `fetch.SkillFetch` and the module global `fetch.SKILL_FETCH_DEADLINE_SECONDS`; `markdown.SkillMarkdown.parse`; `loader.SkillLoader` with `load()` and `documents()`; `github.GitHubSkillResolver.resolve`; `local.LocalSkillResolver.read_capped`.
  - On the agent and preload: `JevSkillsPreload(skills=..., decision=..., threshold=..., response=...)` with `.loader`, `.run`, and `._build_batches(message)`; `agent.skill_preload.loader`.
- **Seams the tests patch:**
  - `HttpTransport._send_once`, through `conftest.FakeSkillHttp`, which honors `max_response_bytes`, lowercase headers, and `client.follow_redirects`.
  - `vidbyte.lib.http.transport.asyncio.sleep`.
  - `vidbyte.agents.jev.alignment.skills.DecisionModelHelper`.
  - `GitHubSkillResolver.resolve`, in one grouping test only.
  - `LocalSkillResolver.read_capped`, for `PermissionError` and the thread check.
  - The fetch module's deadline global.
- **Do not read the deadline once:** keep `SKILL_FETCH_DEADLINE_SECONDS` a module global read when `get` runs, not a default argument or a class attribute. Otherwise the AC-24 and rendezvous tests wait the full 25 s and fail at their outer `wait_for`.
- **Request URLs are compared exactly**, as given in §9.2:
  - GitHub refs use `quote(ref, safe="")`, so a SHA ref skips the lookup.
  - The tree query is `?recursive=1`.
  - Raw paths use `quote(folder + "/SKILL.md", safe="/")` and `?ref=<sha>`.
  - Vendor bases are `https://api.anthropic.com/v1` and `https://api.openai.com/v1`.
- **Detail checks are loose:** they look for keywords, case-insensitive, often any-of: the path, the env-var name, the status number, `path=`, `next run`, `unexpected`, `content route`, `zip`, `api_key=`, `token=`, and the step's `SkillFetchStep` value. They never check whole sentences.
- **Every test applies `_isolated_skill_environment`:** it removes `GITHUB_TOKEN`, `ANTHROPIC_API_KEY`, and `OPENAI_API_KEY` and changes into `tmp_path`.
- **Expect one skip on Windows:** the lowercase-`skill.md` local row skips on case-insensitive filesystems; the symlink rows need symlink rights.
- **`BaseAgent.arun` wraps errors:** it re-raises every non-cancellation error as `AgentExecutionError` from the original. AC-15 therefore checks `__cause__` at the agent and the raw error at `JevSkillsPreload.run`, so do not add a wrapper of your own in the loader or the preload.

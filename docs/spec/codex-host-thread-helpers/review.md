## What the implementation gets right (so nobody "fixes" it)
- **Names, order and the delete rule are exactly as asked.** `CodexHost` gains exactly the 12 §8.5 methods with the §8.5 signatures (checked by `inspect.signature`), in order after `start_codex_review`.
  - `CodexHostTools(...).names()` has 26 entries. `"delete_codex_thread" in names()` is `False`.
  - The 11 new tools match the §9.2 table on permission, properties, `required` and `additionalProperties: false`.
  - `toolsets/codex.py:3` and `:69-71` say that delete has no tool.
- **"Check that the command actually ran" holds on every exit path.** The statement after `spawn_codex_thread` returns is the `try:` (`skill_functions.py:106-122`, `:148-166`). A mismatch, a `None` from the deadline or from running out of rounds, a `CodexAgentError` (re-raised with the `*_UNCHECKED_MESSAGE` suffix, code, operation and next step kept) and any other `BaseException`, cancellation included, each send exactly one `_interrupt(handle)` before raising.
  - The read-back is bounded twice: by attempts, and by one `loop.time()` deadline checked before each wait.
  - It uses no `asyncio.timeout`, so a read already in flight is never cut short (EC-50).
  - S064 stays at its 4 baseline findings. Mutants M07, M09, M15 and M22 are killed.
- **No READ path loads a thread, and no helper runs a spend check (INV-10, INV-33).** The only new `thread/resume` is `CodexThreadHelpers._resume` (`thread_helpers.py:271-276`). Its one caller is `compact` (`:166`), after `_refuse_unfinished`.
  - The added code calls nothing that reads `account/*`, rate limits, sandbox readiness or `model/list`. Mutants M06 and M13 are killed.
- **Compact and delete hold the thread without a race.** Each runs `require_idle` and `reserve` with no await between them (`:157-158`, `:179-180`), and releases in `finally` (`:172`, `:192`). Mutants M10, M14 and M26 are killed.
  - This list does not cover delete's reservation and release, which no test protects (R-4). It is about the code's shape.
- **The settled deviations are built exactly as decided.**
  - D-9: an empty window returns `()`.
  - D-14: an idle loaded thread is deleted, and a busy one is refused, with no resume.
  - R-17: an ephemeral skill run is refused before `list_codex_skills`.
  - D-5: argument errors are `ConfigurationError`.
  - The constant keeps its spec name, `CODEX_HOST_INPUT_CHECK_ATTEMPTS` (§12.4 forbids renaming it).
- **Layering and placement follow the plan.**
  - The five records are frozen, slotted dataclasses in `lib/dataclasses/codex_host.py`.
  - `CodexSkillScope` and the 12 operations live in `lib/enums/codex.py` and are exported.
  - The §9.3 constants are appended to `__all__` in definition order.
  - `CodexSkillFunctions` reaches the host only through the `CodexSkillHost` Protocol and never imports `host.py`.
  - Importing the package loads no `openai_codex` module (INV-31).
- **The host stays guard-then-delegate.** Each new `CodexHost` method is operation, `_guard`, then one delegation; `list_codex_skills` is inline, as the spec allows.
  - Call chains are one level deep, main functions are narrated, and every added `#` line is within 72 columns.
  - `host.py` has 891 lines (cap 900), and the new modules have 279, 251, 238 and 211.
- **Every call is bounded and mapped.** Every Codex call goes through `CodexConnection.call` (300 s bound, mapped `codex.*` codes), and the four new codes have classification rows and next steps that match §9.2 character for character.
  - The listing walk is capped at 1,000 pages and lineage at depth 100.
  - Lineage catches only `session_not_found` from ancestors and re-raises everything else (M17 is killed). A hung app-server therefore fails with one bounded error.
- **The model-facing text follows the house contract.** All 22 new descriptions have 4 sentences and no examples. The WRITE descriptions say they start paid work. No constant name contains `TOKEN`.
- **The gates hold.**
  - `SDK-LINT: PASS`, with A002 improved, and the A007, C008, S008, S024 and S064 ratchets at or under their baselines.
  - The public API contract is current.
  - The byte-pinned paths have an empty diff.
  - `git diff 33787d9a..c81ba632 -- tests/` is empty, and `lint/baseline.json` is untouched.

## What the implementation gets right (so nobody "fixes" it)
- **AC-1 and the journal flow.** The §4 snippet runs verbatim and offline: it prints the root's answer, `memory/seed/brief.md` equals `brief.md`, and the three bookkeeping files exist. The journal runs `run_started` → (`pair_started` → `pair_finished`) → `run_finished`. Committed entries carry `by=root/<name>/gen` and `verified_by=root/<name>/ver`. Leave `agent.py`, `runtime.py`, and the journal flow alone.
- **Scope matches §12.3 exactly.** The diff has 18 added and 15 modified files, all §12.3 paths. `tests/` and `lint/` are byte-identical to S2 (`d8bcdf14`), and `lint/baseline.json` is unchanged. `base.py` changes only the frozenset member, its comment clause, and the header line. There is no new dependency, error class, settings field, prompt leaf, enum member, or record field, and no §3 non-goal is implemented.
- **Batch admission is check-then-reserve with no `await` in between** (`launch.py:124-133`). The whole batch is validated before any `pair_started` record, sibling generators that launch nested batches cannot interleave past `max_agents`, and a replay-only batch skips `ParallelPipeline` (`launch.py:137`). A finished key replays its card with the label, and `agents_started` counts journal records from before a resume too (INV-9/10/11/25/26, D-22).
- **The journal is a correct write-ahead log.** Each record is opened, written, flushed, fsynced, and closed under a class lock (`journal.py:180-189`). A torn tail is skipped on read and truncated before the next append, and a complete last line without its newline gets one (D-25). `find` checks the run id against the pattern before it builds a path, and AC-21 plants a decoy journal to prove it.
- **Every workspace write is synchronous under one class-level lock.** Usage is recounted from disk inside the lock, and ids are `max(live ∪ superseded) + 1`, so concurrent pairs never share an id (AC-5 asserts it).
- **Path rules hold on Windows** for case variants, traversal, other drives, and root-relative paths (`resolve()` returns the on-disk case there; macOS is R-2).
- **Cancellation propagates.** The guard tuple `(VidbyteSdkError, OSError, ValueError)` leaves `BaseException` alone, and AC-23 proves the journal stays resumable.
- **Weighted words are honored.** The root prompt says "Ruthlessly delegate work to subagents". Depth and parallelism default to 10. The verifier runs after its generator and holds the same writing tools. Pair entries are staged and committed only after a verdict. No prompt leaf carries a coding, repo, or worktree rule.
- **Placement is clean.** The six enums are in `vidbyte/lib/enums/infinite.py` and exported. The six frozen, slotted, validated records are in `vidbyte/lib/dataclasses/infinite.py`. Settings are in the agent's own `settings.py` (AGENTS.md exception 1), and every constant is in `vidbyte/lib/constants/infinite.py`; `launch.py` and `memory.py` define no module constants. The toolset imports nothing from `vidbyte.agents` (A006 unchanged), and the registry imports through the facade.
- **Runtime wiring follows `runtime-boundaries.md`.** The work consists of the enum member, the registry row, membership in `_LINEAR_LOOP_RUNTIMES`, a refusal that names InfiniteMemoryAgent, and `launch_subagent` marked `metadata={"internal": True}`. `BaseAgent._runtime()` builds a new runtime for every run, so mutating `self.tools` needs no restore (JevRuntime precedent).
- **Docs and exports are complete.** The 40-leaf family matches its enum (138 assets, 34 families). The prompts README has its row and entry. The folder README has a File Index and Notes for agents and is under A009. The REPO_MAP entries are general prose. The public-API contract is current (`--check`). Every new module has the full A001 header, and each `@intent` is the first line of its block.
- **The gates hold.** `python lint/run.py` ends `SDK-LINT: PASS`, the pack gives `89 passed`, and production code has no suppressions. Every module body is ≤ 358 lines, with no nested defs or lambdas. The stop reason is stored as a plain string.

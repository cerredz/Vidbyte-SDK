### R-2 [Major] [L5/L6] §9.1, AC-12, §15 A-13 — pricing rows are keyed by the request id, but the ledger prices the response-echoed `model`

- **Evidence.** `vidbyte/agents/pricing/tracker.py:76-111` `_record`: `cost = usage.cost_usd(self._pricing.resolve(provider, str(model)))` where `model` is `response.model`. `ModelPricingRegistry.resolve` (`registries/pricing.py:184-200`) tries exact → `ProviderModelRegistry.normalize_model` (strips only a `<provider>/` prefix, `models.py:200-208`) → longest key-prefix of the canonical name. A-13 assumes "Every host echoes a non-blank `model` string" and covers only the *absent* case ("falls back to `config.model` … a `SystemOneHost` flag"); nothing covers an echo that is not a pricebook key. Research facts: §3.3 Foundry body is `{"model":"<deployment name>", …}` — the catalog slug `microsoft-decision-1` is not the wire id, yet §9.1 defaults the model to the slug and FR-4 prices only the slug; §3.4 Cloudflare `usage` fields are "not described" and the `model` echo value is undocumented — an echo such as `@cf/cloudflare/clef` fails every `resolve` step (prefix `@cf…` does not start with `clef`); §3.2 Perplexity documents `model` in the response without saying whether it is the alias or a versioned id. `provider-api-contracts.md`: "Price the *versioned* model ID the response reports, not only the aliases."
- **Failure.** Paid Foundry/Cloudflare (and possibly Perplexity) calls are metered with `cost_usd=None` although the pricebook the user asked for has a row — a silent under-count that AC-12 would not catch because its scripted responses echo whatever the test author guesses.
- **Smallest fix.** (a) Add an "echoed `model`" column to §9.1 sourced from research §3.x, marking Cloudflare/Foundry/Liquid/Baseten/meraGPT "undocumented". (b) Make A-13's flag concrete on `SystemOneHost` (e.g. `model_from_request: bool`): `SystemOneAnswers.model(parsed)` returns `config.model` for hosts whose echo is undocumented or caller-chosen (Foundry) and the echo for TypeSafe/Perplexity/OpenAI — TypeSafe behaviour unchanged. (c) For Foundry, state in §9.1 and the README recipe that `model` is the deployment name and that the pricing row matches only when the deployment is named `microsoft-decision-1` (or price on the request model per (b) and say so). (d) AC-12: give each scripted response the `model` value the host documents, and add one case where the echo differs from the request to pin (b).

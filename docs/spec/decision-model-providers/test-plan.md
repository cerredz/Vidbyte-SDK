# Test plan: Decision model providers

Spec: `docs/spec/decision-model-providers/spec.md` r3 (scoped grants for r6 and r8 are recorded under "Test changes after S2") · Framework: `unittest.TestCase` / `unittest.IsolatedAsyncioTestCase` collected by pytest 8.3.5 with pytest-asyncio 1.3.0 · Prior art copied: `tests/test_jev_agent.py` (`ScriptedTransport`, `_response`, `_runner`, `_score_answer`, `_choice_body`), `tests/test_jev_managed_gateway.py` (positional config, `_TypeSafeCallBuilder` repr check), `tests/test_jev_usage_ledger.py` (`usage_ledger_scope`, `record_billed_failure`), pack layout of `tests/features/sdk_model_usage/`

Pack: `tests/features/decision_model_providers/` — `FEATURE.md`, `README.md`, `decision_fixtures.py` (shared transport, section 4 request, System One / OpenAI response builders, the section 9.1 host table `HOST_ROWS`, keyed runner factory), eight `test_decision_*.py` files, 72 tests at S2 and 87 after the r8 grant (the seven r8 hosts live in a separate `R8_HOST_ROWS` table; `ALL_HOST_ROWS` is the sixteen-row union). Every new symbol (`ModelProvider.PERPLEXITY` …, `vidbyte.providers.systemone`, `DecisionAuthScheme`, `resolved_model()` …) is resolved inside the test body or through `decision_fixtures.provider_member()`, so a missing implementation fails one test, never the collection.

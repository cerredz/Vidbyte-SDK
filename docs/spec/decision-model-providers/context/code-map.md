- `## Repository Map` line 11: "**Do not grep, glob, or read files under `docs/` as part of ordinary work:** those design documents are large and not kept in sync with the implementation, so treat the folder as opaque unless a human names a specific document and asks you to read it."

- `### 1. Keep Call Chains One Level Deep`: "one main function that calls a flat list of helpers, where each helper does its job and returns without calling further helpers of its own."
- `### 4. Use Validated Dataclasses for Core Inputs and Outputs`: "Prefer `@dataclass(frozen=True, slots=True)` ... type any field whose value comes from a small, closed set as an enum."

- `### Enums go in vidbyte/lib/enums/`: "**Every new enum ... is defined in `vidbyte/lib/enums/<domain>.py`**, and every public enum is added to the export list in `vidbyte/lib/enums/__init__.py`. There are no exceptions."
- `### New JEV code`: "**A record** goes in `vidbyte/lib/dataclasses/jev.py`, **an enum or enum member** in `vidbyte/lib/enums/jev.py`, and **a constant** in `vidbyte/lib/constants/jev.py`. Never create a `types.py`, `enums.py`, or `constants.py` under `vidbyte/agents/jev/` or `vidbyte/lib/jev/`."
- `### Existing code`: "Editing one in place (adding a field or a member) is fine. Moving it to `vidbyte/lib/` is a change of its own".

### 4.1 Answers to the briefing questions (a)-(h)
- (a) `ModelProvider` binds to usage via `usage_class()` → `_usage_class_map()` (`model_provider.py:47-76`), a `@cache`d dict built with a call-time import of `vidbyte.agents.pricing`; TYPESAFE → `JevUsage`. The env var is NOT on the enum: it is `ProviderModelRegistry.API_KEY_ENV_VARS[ModelProvider.X]` (`registries/models.py:73-88`); endpoint in `DEFAULT_ENDPOINTS` (90-105); default model in `DEFAULT_PROVIDER_MODELS` (56-71). S014 enforces all three.
- (b) `DecisionModelConfig.__post_init__` (`model_configs.py:353-374`) validates provider in `DECISION_SUPPORTED_PROVIDERS` (= `{TYPESAFE}`), mode type, managed-endpoint ban, non-empty model, `timeout_seconds > 0.0`, non-negative int `retry_count`; key is resolved only by `validate()`/`resolved_api_key()` (390-407): managed → `VIDBYTE_API_KEY` `vb_live_...` regex; direct → `ProviderModelRegistry.resolve_api_key(provider, api_key)`. Endpoint: managed → `VIDBYTE_JEV_GATEWAY_ENDPOINT`; direct → `ProviderModelRegistry.resolve_endpoint(provider, endpoint)` (409-417).
- (c) `JevDecisionRequest(state: JevContent, questions: tuple[JevQuestion, ...])` (`jev.py:300-321`). `JevQuestion(name, question_type: JevQuestionType, instructions: JevContent, options: tuple[JevOption, ...] = ())` (253-296). Kinds (`enums/jev.py:17-22`): `NOUL = "noul"`, `CHOICE = "choice"`, `SCORE = "score"`. NOUL is the yes/no kind: options may only be `true`/`false` (`JEV_NOUL_OPTIONS`), answer keys are exactly `{"true","false"}`, `noul` = P(true), `confidence` and `score` must be None (`jev.py:360-366`). SCORE: 2..10 ordered levels, `score` = weighted level index in `[0, levels-1]`, `confidence` required.

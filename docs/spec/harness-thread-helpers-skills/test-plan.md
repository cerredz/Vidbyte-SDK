# Test plan: Thread helpers and built-in skill functions for the Grok, opencode and Muse harnesses
Spec: `docs/spec/harness-thread-helpers-skills/spec.md` r3 · Framework: pytest 8.3.5 + pytest-asyncio 1.3.0 (Python 3.11.0 venv) · Prior art copied: `tests/features/harness_threads/test_harness_threads_arguments.py` (`refuse`), `test_harness_threads_credentials.py` (snapshot), `test_harness_threads_process_bounds.py` (bounds, cancel), `test_harness_threads_wsl.py` (WSL stand-in), `test_harness_threads_acceptance.py` (§4 snippet in a subprocess)

All new files live in `tests/features/harness_threads/` and are named `test_harness_threads_<topic>.py`; below, `X.py` stands for `test_harness_threads_X.py`. Every vendor is the stand-in `fake_harness.py` (plus its sibling `fake_harness_helpers.py`), run as a real child through `CliRunner`; nothing in the SDK is mocked. Only the documented timing knobs (`NATIVE_CONTROL_TIMEOUT_SECONDS`, `NATIVE_KILL_WAIT_SECONDS`) are shrunk through the constants module.

## Notes for the implementer
- **Names the tests bind to.** The 47 functions of §8.5 by exact name and parameter names (`helper_surface.py` pins every signature and default); `NativeThreadSummary`, `NativeCommandOutput`, `GrokThreadScope`, `GrokCommand` exported from `vidbyte.harnesses.native`; the §9.1 enum members in order; `FailureCode` + 4; the §9.3 constants in `vidbyte.lib.constants.native_threads`, including `NATIVE_OPENCODE_SCAN_MAX`, `OPENCODE_SESSION_QUERY`, `MUSE_EXPORT_PARTS`, `MUSE_GOAL_PROMPT_TEMPLATE` (any value containing `{prompt}`), `GROK_SUMMARY_MAX_BYTES`, `GROK_SUMMARY_GRACE_SECONDS`, `NATIVE_LINEAGE_MAX_DEPTH`; and `RecordFieldConverter.to_utc_datetime`.
- **Timing knob.** Read `NATIVE_CONTROL_TIMEOUT_SECONDS` (and `NATIVE_KILL_WAIT_SECONDS`) through the constants module at call time, as #1036 does; the bound tests shrink it with monkeypatch and pass `config.timeout_seconds=600` to prove it is ignored (D-14).
- **Exact argv the tests compare.** Grok command runs: `--output-format=streaming-json`, `--session-id=<uuid4>`, `--cwd=<ws>`, `--permission-mode=<mode>`, then `--model`, `--reasoning-effort`, `--agent` when set, then `--single=<line>` (§12.3 row 21 order). opencode commands: `run --format=json --dir=<ws> --model=<m> [#1036 options] --command=<c>` or `--agent=plan`, arguments on stdin and an empty stdin without them. opencode list: `session list --format=json --max-count=10000`, cwd and `PWD` = ws. opencode get: `db --format=json <OPENCODE_SESSION_QUERY>`. Muse export: `export --session <id> --out <tmp>/export/thread.json`, cwd `<tmp>/export` (empty).
- **Exact frames.** `session/list` params are exactly `{workspaceRoot, limit, updatedAfter}` with `updatedAfter` only when `since` is given (RFC 3339) and `caller limit <= limit <= 200`; get and lineage send `{sessionId, excludeItems: true}`; the skill evidence read sends `{sessionId, excludeItems: false}` once.

## What the implementation gets right (so nobody "fixes" it)
- **Scope is exact and observation-only.** Every §12.3 row is done, with the prescribed wording. The source diff touches exactly the 13 files of §12.3. `vidbyte/agents/runtime.py`, `base.py`, `vidbyte/middleware`, `vidbyte/pipelines`, `vidbyte/__init__.py`, `contracts/`, and `lint/` have an empty diff. S3 changed no test. There is no suppression and no baseline edit.
- **G-5, INV-5, and INV-6 hold beyond AC-21 and AC-26.** The conformance probe ran a tree with a refusal, a replay, a rule drop, an unchecked drop, a child error, and an AC-13 abort. On that tree, model-visible text and workspace files are byte-identical with a sink and without one. A sink that raises on every kind leaves the reply, journal, disk, and model calls unchanged (AC-22). Two runs give equal 47-event streams once normalized.
- **INV-1: no cost without a sink.** Every public method returns before it builds anything when `on_event is None` (AC-20).
- **D1 is derived, not observed.** Denials are read only from existing DENIED `ToolCallContext`s that carry a `limit`, which only `delegation_limits.py:55,67` sets. `state.call_contexts` is append-only, and `tool_calls` is `tuple(call_contexts)`. So the single high-water mark (`runtime.py:157-164`) can never announce a denial twice, and the catch-up before `journal.finish` puts every root denial before `run_finished`. Keep the single index; do not switch to a set of call ids. `InfiniteRunJournal.started` is a read-only tuple view, and the journal format is unchanged.
- **`in_flight` accounting is right on every listed path.** A launch counts once even when the sink raises (`events.py:333`), and so does a finish (`events.py:421`). An abort after a journaled finish does not count again (EC-10, `events.py:463`). An abort with no journaled finish does count (EC-25). The count is floored at 0, and every counter starts at `INFINITE_MIN_COUNT` = 0. Deviation 1 (the changes sit just outside the shield) gives the same behaviour, and it holds A007 at its baseline of 255. Do not move these lines inside `_shielded` or after `_deliver`. The guard `journal.finished` is a dict `get` and cannot raise.
- **`_level` is stored before delivery** (`events.py:266-271`).
- **The §4 snippet runs verbatim** (AC-1).
- **The lint loop did not move.** It ends `SDK-LINT: PASS`, every per-rule count equals base `181f1992`, and the JSON findings for 12 rules are byte-identical. No A007, A002, S024, or S008 finding was added. The public-API contract is current at 678 exports.
- **Placement and exports follow AGENTS.md.** The 3 enums are in `vidbyte/lib/enums/infinite.py` and in `vidbyte.lib.enums.__all__`, and not in `vidbyte.__all__` (NG-12). The 8 records are frozen and slotted, with no defaults, and are validated only through `RecordFieldValidator` and `RecordFieldConverter`. Every meaningful literal is in `vidbyte/lib/constants/infinite.py`.
- **The call shape is flat.** The 22 public `InfiniteEvents` functions are exactly the 22 kinds. Each has the same three steps: the early return, then `_shielded`, then `_deliver`. `_rule`, `_quota`, `_launcher_role`, `_usage`, `_count`, and `_cut` are leaf helpers, and `_rule` dispatches with one `match`. The single added `except BaseException` (`launch.py:313`) announces the abort, then re-raises with a bare `raise`. Every new step is narrated, and each `@intent` sits within 20 lines of its `def`.
- **Comments and READMEs follow house style.** Added comment blocks are at most 72 columns. The stale comments named in §12.3 were rewritten. The package README lists all 22 kinds and is A009-clean at 23,230 characters, and `vidbyte/agents/README.md:183` matches row 14.
- **Input the model controls is parsed defensively.** `map_omitted` returns 0 for a 5,000-digit count, superscript digits, a missing count, or an empty map, and it returns 12 for a well-formed line. All workspace raise sites keep their messages byte-identical and only add `details["rule"]`.
- **[verifier] `run_finished`'s new `files.jsonl` read cannot drop the terminal event on a damaged file.** `InfiniteWorkspace._text` reads with `errors="replace"`, and `_descriptions` skips any malformed line (`workspace.py:275-278`, `:359-371`).
- **[verifier] `deepest`'s key split is sound.** Task names match `^[a-z0-9][a-z0-9-]{0,63}$` (`INFINITE_TASK_NAME_PATTERN`), so a name can never add a `/` segment.

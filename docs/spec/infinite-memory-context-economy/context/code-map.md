Under **General Coding Style Guidelines** ("They apply to new code and to code you change. Do not rewrite untouched code just to make it conform"):
1. *Keep Call Chains One Level Deep*: "a function may call another of its own functions, but that second function should not call a third … Avoid defining functions inside other functions as well, unless an API requires a callback or a decorator."
2. *Narrate Main Functions in Plain English*: "place short plain-English comments throughout the body … When you change the steps of a main function, update its comments in the same edit".
3. *Build in Layers of Small, Single-Purpose Classes*: "nothing in `vidbyte/lib/` may import from a layer above it … Keep files well below 1,000 lines; when a file heads toward four digits, split it into smaller modules along subsystem lines before adding more."
4. *Use Validated Dataclasses*: "Prefer `@dataclass(frozen=True, slots=True)` … type any field whose value comes from a small, closed set as an enum … Define each new dataclass in `vidbyte/lib/dataclasses/<domain>.py` and each new enum in `vidbyte/lib/enums/<domain>.py`".
5. *Write Shared Logic Once, as a Canonical Helper in `lib/`*: "look in `vidbyte/lib/` for a helper that already does it, and if one is close, add the option you need to it rather than copying it into a variant beside your feature."

Under **Placement Rules**:
- "Every new dataclass is defined in `vidbyte/lib/dataclasses/<domain>.py` … Add to the existing domain module when there is one". The exception that applies here is "**Agent settings objects.** A `*Settings` class that configures an agent lives … in the owning agent's own `settings.py`".
- "Every new enum … is defined in `vidbyte/lib/enums/<domain>.py`, and every public enum is added to the export list in `vidbyte/lib/enums/__init__.py`. There are no exceptions." Also: "Any field, parameter, or registry key whose value comes from a small, closed set is typed with an enum from this folder, not a plain `str`."
- *Existing code*: "Do not copy them as precedent. Editing one in place (adding a field or a member) is fine. Moving it to `vidbyte/lib/` is a change of its own". This applies to `CompactionMode` in `vidbyte/middleware/compaction/base.py`, which predates the rule.

## Hypotheses tried, including the ones that did not hold

- **R-2, test assertion.** The first version asserted `relative(path) == path`. A stdlib probe on Python 3.13 (`py -3.13 -I`) showed that 3.13's `Path.resolve` no longer raises on a loop and returns the other link (`notes/b.md`). That test would fail on a supported Python outside the CI matrix (3.11, 3.12). The test now asserts one workspace-relative name, used by both the handoff line and the event, and the exact path on 3.11 and 3.12 (`1dbfdd84`).
- **R-4, how to count.** The log check alone is not enough. With placeholder arguments, `run_stopped` builds a whole `InfiniteEvent` without raising, so a dropped early return there logs nothing. The `__post_init__` spy catches it (`no_sink_run_stopped` KILLED). Deleting the `_deliver` guard stays refuted (mypy S009, review).
- **R-7, where the helper lives.** I considered three homes. (1) A new class `TextCut`: it adds a 23rd class beyond §8.4, and the briefing said "the existing class". (2) `SubstringCounter`: the wrong concern. (3) `TokenEstimate`, which already holds the `cut` and `cap` text budgets. I chose (3) and broadened its docstring. The name is `truncate_chars`, not `cap_chars`, because `cap` puts the marker after the cut while this keeps it inside the limit.
- **Tooling.** Bash heredocs in this Git Bash collapse `\\` to `\` inside a quoted heredoc. One edit script therefore wrote a real lone surrogate and truncated a test file to 0 bytes; I restored it from the commit with `git checkout --`. Edits that contain backslashes now go through the Edit tool. The scratch venv's `semgrep.exe` launches the global `pysemgrep` (mcp 2.x crash) unless the venv's `Scripts` comes first on `PATH`, written as `/c/...` because a `C:` path breaks `PATH` parsing.

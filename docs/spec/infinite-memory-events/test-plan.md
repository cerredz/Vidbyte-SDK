# Test plan: InfiniteMemoryAgent native run events and handoff

Spec: `docs/spec/infinite-memory-events/spec.md` r3 · Framework: pytest 8.3.5 + pytest-asyncio 1.3.0 (strict markers, function-scoped loop, no conftest) · Prior art copied: `tests/features/infinite_memory_agent/test_infinite_memory_resume.py` (cancellation without sleeps, hand-written journals), `tests/features/infinite_memory_agent/test_infinite_memory_delegation.py` (batches, replay, nesting, middleware denials), `tests/features/infinite_memory_agent/test_infinite_memory_acceptance.py` (the section 4 snippet run as printed), `tests/test_record_field_validation.py` (direct validator calls checked by `details["field"]`)

53 test functions (73 collected cases) in 8 new files, plus the one pre-approved edit of `test_new_modules_stay_inside_the_complexity_budget` (spec section 12.3 row 22). File names below are short: `stream`, `lifecycle`, `pairs`, `records` = `tests/features/infinite_memory_agent/test_infinite_memory_events_<name>.py`; `handoff` = `tests/features/infinite_memory_agent/test_infinite_memory_handoff.py`; `options` = `tests/test_record_field_validation_event_options.py`; `truncate` = `tests/test_output_text_truncate_marker.py`; `fixtures` = `tests/features/infinite_memory_agent/infinite_events_fixtures.py`.

Levels: **run** = a whole `InfiniteMemoryAgent` run with only the model runner scripted (`ScriptedTree`) and a real sink; **writer** = a real `InfiniteEvents` driven directly with a real workspace, journal, launch tool, and memory; **record** = the lib records built directly; **helper** = a lib helper called directly.

Every run-level test that collects events ends with `assert_portable(seen)` (`fixtures`), which checks each event's envelope, its JSON form under `ensure_ascii` true and false, its leaf types, its summary (one line, 1 to 280 characters), its key (ASCII, at most 512), and its details size (at most 32,768 bytes under all four `json.dumps` settings). The expected cut text is built by `cut`/`line` in `fixtures`, which restate INV-12 without calling `OutputText`.

## Tests deliberately NOT written

| Candidate | Why it would not earn its keep |
|---|---|
| EC-1: a sink raising `ValueError` on `subagent_launched` in a batch of 3 | AC-4's sink raises on every event, `subagent_launched` included, and requires byte-identical journals and model calls; three pairs add no code path. |
| EC-4: `on_event=[]` | The same `callable()` check as `42` and `"x"` in AC-21. |
| EC-6: `journal.finish` raises `OSError` after the loop | Needs a faked journal or a full disk; the journal is a real seam (spec section 13). The `try`/`except BaseException` around the whole run is pinned by AC-5, AC-6, and AC-27. |
| EC-7: `InfiniteRunJournal.start` fails | No run id exists, so the only assertion is "no event"; producing the failure needs a read-only `.runs/`, which Windows does not give with `chmod`. |

## 4. Notes for the spec author

### 4.1 Contradictions ("request assumes X; code shows Y")

1. **Unpriced vendors.** The request assumes a vendor without a pricing page can "follow the repo's rule for unpriced models" (`request.md:38`). The code shows that rule covers only non-default models:
   - `pricing.py:61-64` says "Providers/models with unverifiable rates are omitted".
   - **C009** (baseline 0) requires every token-priced default text model to resolve (`lint/rules/c009_default_model_priced.py:196-207`). Its only exemption is `_PRICED_PER_RESPONSE`, which holds OpenRouter alone, because OpenRouter returns `usage.cost` (`:29-31`).
   - C009's `will_not_work` (`:294`) rules out an empty provider block, a guessed rate, switching the default, and a raised baseline.
   - `vidbyte/providers/README.md:614-616` ("Omit the model rather than guessing") predates C009. Mistral (`81bced94`) landed unpriced before C009 existed (`test_catalog_pricing_contract.py:368`).
   - So a text provider whose default model has no first-party price cannot pass the gate.
2. **Every priced provider edits the same lines.**
   - Adding rates forces a later `PRICING_AS_OF` (`pricing.py:58`), a refreshed `lint/pricebook_vintage_lock.json` (C010), and an edit to the hard-coded vintage pin `test_catalog_pricing_contract.py:376-379`.

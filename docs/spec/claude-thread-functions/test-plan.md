# Test plan: Run, continue and fork Claude Code threads with the caller's API key

Spec: `docs/spec/claude-thread-functions/spec.md` r3 · Framework: pytest 8.3.5 + pytest-asyncio 1.3.0 (strict) · Prior art copied: `tests/features/harness_threads/`

All tests live in `tests/features/harness_threads/` (no new folder: the spec's §13 names this pack, and the shared `conftest.py`/`fake_harness.py` already hold the real seams). Ten new files, all prefixed `test_harness_threads_claude_` (written `claude_<x>` below), hold 188 tests; 6 more come from adding `"claude"` to the harness list of `test_harness_threads_errors.py`. Every vendor program is `fake_harness.py` started as a real child process; `CliRunner`, `NativeLauncher`'s PATH lookup, `NativeErrorFactory` and the filesystem are real (spec §13 "Real seams"). Levels: **unit** = a record, enum, constant or helper called directly; **integration** = a public thread function awaited against the stand-in; **e2e** = the §4 snippet run as a separate Python process; **static** = source or git inspection.

## What the implementation gets right (so nobody "fixes" it)
- **The user's request is met end to end.** The §4 snippet prints exactly `claude True True` and then the fork's answer against an independent stand-in. Every call's argv is exactly the AC-5 form. The prompt goes only on stdin, and the child's working folder is the resolved workspace.
- **Key isolation holds in a hostile environment.** With 12 real `ANTHROPIC_*`/`CLAUDE*` variables inherited, including a real key, `CLAUDE_CONFIG_DIR` and `CLAUDECODE`, the child saw only the caller's `ANTHROPIC_API_KEY` and the private `CLAUDE_CONFIG_DIR` (= `sha256(normcase(resolved ws))[:16]`). It also got the two switches and the kept `CLAUDE_CODE_GIT_BASH_PATH`. The strip is case-correct on Windows, and AC-6 asserts the exact name list, so a prefix typo that let `CLAUDECODE` through would fail it.
- **The key path is tight.**
  - The key travels only in `env_overlay` (`claude/threads.py:151`).
  - `register_secret` runs before the child starts (`:110`).
  - `protocol_mismatch` never copies stdout (`wire.py:73`, `:76`).
  - Redaction covers the `result` text, the `errors` list and bare-exit stderr.
  - The AC-7 random-key echo test would fail if `register_secret` were dropped.
- **`ClaudeWire.read` classifies in the INV-7 order at C901 complexity 8.** `isinstance(status, int)` comes before the frozenset lookup, so list or dict statuses are `run_failed`, not a `TypeError`. A continue keeps the caller's id even when Claude names another session.
- **Scope and removal are exact.**
  - The 21 changed code files are exactly the §12.3 rows.
  - `pyproject.toml`, `vidbyte/tools/`, `vidbyte/lib/errors/__init__.py`, `lint/`, `vidbyte/lib/configs/`, root `vidbyte/__init__.py` and `contracts/` are byte-identical to `b28c3027`.

- **Grok's switch to `NativePrivateFolders.prepare` is behaviour-preserving.** The helper body matches the deleted `_prepare_home` expression for expression, with the constants as parameters, and all 131 Grok tests pass. Among the siblings, only `grok/threads.py` changed. The `hostkit/errors.py` diff is comment and header text only.
- **The public surface matches #1036 for all four harnesses.**

  - `vidbyte.harnesses.native.__all__` has 23 names.

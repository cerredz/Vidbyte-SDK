## Purpose

The extra tools this pair needs beyond the preset tools every agent holds.

## How to write it

Name each tool exactly as you hold it, and only when the work needs it, because every tool the pair holds adds its description to the pair's context on every call. Leave the list out when the preset tools are enough.

## Rules

You can grant only extra tools you hold yourself, since a pair never gains a tool its parent lacks, and any other name refuses the whole call. Both agents of the pair receive the tools named here, and a generator can hand on to its own subagents only the extras it received. Name each tool once.

## Purpose

The exact passage to replace in the file.

## How to write it

Copy the passage from a fresh read of the file rather than from memory, because the match is exact, including spacing, line breaks, and letter case. Include enough of the surrounding text to make the passage unique, but no more than that, so the edit stays easy to check.

## Rules

The passage must appear exactly once in the file. When it appears more than once or not at all, the edit is refused with the number of matches found, and nothing changes.

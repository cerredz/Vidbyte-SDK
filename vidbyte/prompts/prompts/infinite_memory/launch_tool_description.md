Start subagent pairs that each carry out one task, so the work happens outside your own context. Every task runs as a pair: a generator does the work from its generator_prompt, then a verifier checks it from its verifier_prompt and fixes what it finds, so every task needs both prompts. One call takes 1 to {max_parallel} tasks, and all of them run at the same time. The result is one short card per task, in the order you wrote them, with its status, its verdict, a capped summary and review, and the memory entries it saved. A task whose name already finished in this run is not run again; its recorded card comes back instead.

## Purpose

The staged key of the entry to drop.

## How to find it

Staged keys are the short labels that remember returns when it stages an entry, each the letter s followed by a number. Your first message lists every key the generator staged, with its kind and text.

## Rules

Give the key exactly as listed. A key that is not currently staged, including one already dropped, is refused with the list of keys that are. Dropping cannot be undone, but you can stage a corrected entry with remember.

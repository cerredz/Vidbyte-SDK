## Purpose

A short label that identifies this task's pair on its result card and in the run's journal.

## How to write it

Choose a name that says what the task covers, so its card is easy to match to its task when several come back together. Use only lowercase letters, digits, and hyphens, start with a letter or digit, and keep it short; a name over the length limit is refused with the limit named.

## Rules

The name must be unique within this call. A name that already finished in this run, among the tasks you launched, is not run again, and its recorded card comes back instead. Give new or repeated work a new name, for instance one that adds a word saying what changed.

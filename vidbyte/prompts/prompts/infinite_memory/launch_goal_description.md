## Purpose

The outcome the task must achieve: the shared target that the generator works toward and the verifier checks against.

## How to write it

State the result rather than the steps, in a sentence or two that make sense without this conversation. Name the subject plainly and say what the result is for, because an agent that knows why the outcome matters makes better judgment calls at the edges of its task.

## Rules

Both agents of the pair read the goal. Put the method in the generator prompt and the acceptance checks in the done criteria, so that each field does one job.

## Purpose

A few short labels that help later searches find the entry.

## How to write it

Choose tags that name the topic, area, or line of work the entry belongs to. Reuse the tags that existing entries already carry for the same topic, so that one search finds them together. Leave the list out when no tag would help a later search.

## Rules

Each tag uses only lowercase letters, digits, and hyphens, starts with a letter or digit, and stays short. The number of tags and the length of each are limited, and a tag list that breaks a rule is refused with the rule named.

## Purpose

The complete brief for the generator, the fresh agent that does this task. It cannot see this conversation, so this text and the context you name are all it knows about the work.

## How to write it

Cover the objective and why it matters to the larger task, the scope and what sibling tasks handle instead, the method, the sources and tools to use, and the constraints. Name where to write the output and in what form, giving each parallel task its own output location. Say what its final answer must report, because that answer becomes the summary on the result card: ask for findings first, then the evidence for each done criterion, the paths of the files that hold the detail, and what is left open.

## Rules

The generator also receives the goal, the done criteria, the entries and paths named in context, and the workspace map, so do not repeat them at length. It can split its own work further with launch_subagent, so say when you expect the task to need that.

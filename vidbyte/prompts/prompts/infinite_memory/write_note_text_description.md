## Purpose

The text to write to the file.

## How it behaves

When the file does not exist yet, this text becomes its whole content. When the file exists, the text is appended directly to its end, so begin with a line break when it should start on a new line.

## How to write it

Write for a reader with no context: lead with the conclusion, keep each source next to the claim it supports, and give each appended section its own heading or label so later readers can find it.

## Rules

The text must not be empty. The file must stay under its size limit, and the workspace under its total limit, after the write, or the whole write is refused and nothing changes.

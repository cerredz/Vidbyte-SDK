## Purpose

References that back the entry or tell a later agent where to look next.

## How to write it

Write each reference as one line that names a workspace file by its path relative to the workspace folder, or an outside source by its address. Give exact paths and addresses, because references are stored as written and are never checked. Leave the list out when the entry stands on its own.

## Rules

The number of references is limited, and each must fit on one line. A list that breaks a rule is refused with the rule named.

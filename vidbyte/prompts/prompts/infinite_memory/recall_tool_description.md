Asks a fresh helper agent to search the shared memory for the answer to one question, and returns what it found. The helper searches and reads on its own, and the found part of the reply holds only memory entries and line ranges copied from the workspace exactly as they are on disk, never the helper's own wording. Use it for a question that would take several searches or reads, so that work stays out of your context; a single quick lookup costs less with search_memory and read_lines. The reply also lists what the helper could not find, the citations of its that were refused and why, and every search it ran. Each agent may start only a few recalls, and a call refused for its arguments or its allowance starts nothing and uses none.

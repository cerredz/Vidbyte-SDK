## Purpose

A one-line description of a new file, shown beside its path on the workspace map that every agent reads.

## How to write it

Say in a few words what the file holds and when to read it, so an agent can decide from the map alone whether the file is relevant to its task.

## Rules

It is required when the file does not exist yet and ignored when it already exists. It must fit on one line and stay under the entry size limit, and a new file with a missing or overlong description is refused. This tool cannot change the description later, so write it for the file's whole life.

## Purpose

The path of the file, relative to the workspace folder.

## How to write it

Choose a folder and file name that say what the file holds, because the workspace map lists every file by its path and other agents decide from it what to read. Group related notes in a shared folder, and give each parallel task its own file, so that sibling pairs never write to the same place.

## Rules

The path must stay inside the workspace, fit on one line, contain no colon, and end in .md, .txt, .json, or .jsonl. Seed files, run journals, and the bookkeeping files of memory cannot be written or edited. A path that breaks a rule is refused with what to fix.

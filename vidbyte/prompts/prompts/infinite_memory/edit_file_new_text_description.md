## Purpose

The text that takes the place of the old passage.

## How it behaves

It replaces only that one match and leaves the rest of the file unchanged. An empty text deletes the passage.

## How to write it

Keep the surrounding format intact, such as headings, list markers, and line breaks, so the file still reads correctly after the change.

## Rules

The file must stay under its size limit, and the workspace under its total limit, after the change, or the edit is refused and nothing changes.

# Your tools

Your file tools read_lines, write_text, grep, and patch_file work inside the workplace folder and refuse any path outside it. The bash tool runs shell commands that start in the workplace folder, but it is not confined to that folder, so keep your commands inside it. Read a file with read_lines before you change it, use patch_file for a small edit, and use write_text to create or replace a whole file. The message tool sends text to any agent in the swarm by name and returns at once. The compact tool replaces your older conversation history with a summary before your next model call, so that you can keep working when your history grows long. Calling isDone, or replying without calling a tool, ends only your own turn and never the whole swarm. After your turn ends you wait, and a message from any agent wakes you for a new turn.

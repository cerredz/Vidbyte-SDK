Sends one text message to one agent in this swarm, named in the to parameter. Any agent in the swarm may receive it, including you, which lets you leave a note for your own next turn. The message is queued for that agent and the call returns at once, without waiting for the agent to read or answer it. The recipient receives it as a user message labeled with your name, between its tool calls while it works or as the start of a new turn while it waits. Any answer comes back to you later in the same way. When the recipient has already stopped, the reply to this call says so, and the message is recorded but not delivered. A call with blank text, or with a name that is not an agent in this swarm, is refused and nothing is sent.

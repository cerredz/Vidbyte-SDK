Sends one text message to one other agent in this swarm. The message is queued for that agent and the call returns at once, without waiting for the agent to read or answer it. The agent receives it as a user message labeled with your name, between its tool calls while it works or as the start of a new turn while it waits. Any answer comes back to you later in the same way, so keep working instead of waiting for it. A message to yourself, to a name outside the swarm, to an agent that has stopped, or with blank text is refused, and nothing is sent.

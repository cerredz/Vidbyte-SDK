# Messaging

The message tool sends one text to one agent by name: any of {peers}, or yourself when you want to leave a note for your own next turn. The call returns at once, and nobody waits for the recipient to read or answer it. Messages to you arrive as user messages labeled with the sender's name, between your tool calls while you work or as the start of a new turn while you wait. A message to an agent that has stopped is recorded but never delivered, and the reply to your call tells you so. Use messages to divide the work, to claim the files you will change, to ask questions, and to report what you finished. Keep each message specific: say what you did, what you need, and which files it concerns. When another agent asks you something or waits on your work, answer it before you move on.

Runs one page-level or form-level episode with a fresh worker that holds the browser tools, on the one browser session every episode of this run shares. The worker sees only the task and the done_when check you write here, plus its own rules, and never this conversation or your goal card. Episodes run one at a time in the order you call them, and each returns one capped result card with the outcome, a summary, and the facts, URLs, and evidence the worker found. The outcome is done, stuck, blocked, or ready_to_submit, and a worker never submits anything itself. Every episode has an action budget and a screenshot cap that the system enforces, so give each one a task small enough to finish within them.

# Integration tools

## Intent

This package contains model-facing tools that are built by external-source
integrations and keep their provider scope in construction-time state.

## Index

- `github/` — repository-scoped GitHub tools.

## Non-goals

These modules do not accept arbitrary hosts, routes, executables, or shell
commands from model arguments.
